### Вариант задания — №23

На прямоугольном поле перемещаются танки, а одно или несколько орудий пытаются их поразить. Каждый танк занимает одну клетку и на каждом такте может остаться на месте либо перейти в соседнюю допустимую клетку. Орудие получает сведения о последнем известном положении цели и выбирает координаты выстрела по случайной или прогнозирующей стратегии. Выстрел имеет задержку между наведением и попаданием. Снаряд поражает указанную клетку, а не идентификатор цели.

**События:** перемещение танка, наблюдение цели, выбор точки прицеливания, выстрел, фактическое положение цели в момент попадания, промах, повреждение, уничтожение.

### Многопоточность

| Участник | Поток | Что делает |
|---|---|---|
| Танк | `tank_thread`, по одному на танк | каждый такт один раз ходит по своей стратегии |
| Орудие | `gun_thread`, по одному на орудие | каждый такт наблюдает, затем (если прошла перезарядка) стреляет |
| Координатор поля | главный поток, `sim_run` | ведёт такты, по очереди запускает фазы, разрешает разрывы снарядов, проверяет завершение |

Такт состоит из четырёх фаз: перемещения, наблюдения, выстрелы, разрывы. Координатор будит участников фазы семафорами (`go` у каждого танка и орудия) и ждёт, пока все отчитаются через общий семафор `done`. Внутри фазы участники работают одновременно, а общее состояние (поле, танки, орудия, снаряды, статистика) защищено мьютексом `ctx->mutex`. Разрывы обрабатываются после всех перемещений такта, поэтому попадание определяется по состоянию поля в момент разрыва. У каждого танка и орудия свой генератор случайных чисел, посеянный от общего seed.

Порядок строк внутри такта может меняться от запуска к запуску, в сценариях с несколькими танками, которые соревнуются за клетки, могут отличаться и сами результаты.
